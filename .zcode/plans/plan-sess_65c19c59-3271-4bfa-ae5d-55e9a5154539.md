
# Plan: Descargador Pro — Multi-Red Social con Selector de Calidad y Formato

## Resumen del Cambio
Expandir la app de "solo TikTok (video/audio)" a un **descargador multi-plataforma** (TikTok, YouTube, Instagram, Facebook, Twitter/X, Reddit, Vimeo, Dailymotion, Pinterest, Twitch) con:
- **Selector de calidad de video** (360p, 480p, 720p, 1080p, 4K, o "Mejor disponible")
- **Selector de formato**: Video (.mp4) o Audio (.mp3)
- **Soporte para múltiples redes sociales** detectado automáticamente por yt-dlp

## Cambios a Implementar

### 1. `server.js` — Backend (refactor mayor)

**a) Nueva función `resolveUrl(url)` genérica**
- Reemplaza `resolveTiktokUrl()` — sigue manejando enlaces cortos de TikTok, pero ya no asume que todo es TikTok
- Para el resto de redes, simplemente limpia la URL y la devuelve tal cual (yt-dlp las maneja nativamente)

**b) Ruta `POST /api/analyze` — mejorada**
- Ya no hardcodea TikTok: remueve la lógica de reescribir `/photo/` → `/video/` solo si es TikTok
- Usa `yt-dlp --dump-json` y extrae del JSON:
  - `titulo` (title)
  - `autor` (uploader)
  - `duracion` (duration en mm:ss)
  - `thumbnail` (thumbnail URL)
  - `plataforma` (extractor key: "TikTok", "YouTube", "Instagram", etc.)
  - `formatos_video` — lista de formatos de video disponibles con `{ id, calidad, extension, tamano, contenedor }`
  - `formatos_audio` — lista de formatos de audio disponibles
  - `esCarrusel` / `esAudio` — detección de tipo de contenido

**c) Ruta `GET /api/download` — nueva ruta unificada**
- Reemplaza las dos rutas separadas (`download-video` y `download-audio`)
- Parámetros: `url`, `formatId` (ID de formato de yt-dlp), `tipo` ("video" o "audio")
- Si `formatId` = "best", usa `best[ext=mp4]/best` para video o `bestaudio/best` para audio
- Si `formatId` es específico, usa `-f formatId`
- Nombre de archivo dinámico: sanitiza el título original para el `Content-Disposition`
- **Elimina** las rutas viejas `/api/download-video` y `/api/download-audio`

**d) Agregar script `start` en package.json**
- `"start": "node server.js"`

### 2. `index.html` — Frontend (rediseño completo)

**a) UI expandida:**
- Placeholder del input actualizado: "Pega el enlace de YouTube, TikTok, Instagram, Facebook..."
- Sección de redes soportadas con iconos (textuales) debajo del input
- Area de resultado con:
  - Badge de plataforma detectada (e.g., "📺 YouTube", "🎵 TikTok")
  - Thumbnail con miniatura del video
  - Título, autor, duración
  - **Selector de tipo**: toggle Video / Audio
  - **Selector de calidad**: dropdown/select que se llena dinámicamente según formatos disponibles
  - Botón "Descargar" principal
  - Indicador de tamaño estimado por formato

**b) JavaScript mejorado:**
- `analyze()` — envía URL al backend, recibe formatos disponibles
- `renderResult(data)` — muestra metadata + llena selectores de calidad
- `updateQualityOptions(tipo)` — al cambiar Video/Audio, actualiza el dropdown de calidades
- `download()` — construye URL con formatId seleccionado y tipo
- Detección de plataforma por icono/color (YouTube=rojo, Instagram=púrpura, TikTok=rosa, etc.)

**c) Mantener estilo dark theme actual**, expandir con:
- Nuevos badges de color por plataforma
- Estilos para el select dropdown y thumbnails
- Layout responsivo mejorado

### 3. `package.json`
- Agregar script `"start": "node server.js"`
